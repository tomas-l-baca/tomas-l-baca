The **Excel Governance Engineering Assistant** is a GPT-style AI workflow application designed to help users work through Excel automation, VBA guidance, formula design, recurring data cleanup, and structured spreadsheet problem-solving.

This project was built as a proof artifact to demonstrate practical AI-assisted application building, workflow design, and Google Apps Script development.
